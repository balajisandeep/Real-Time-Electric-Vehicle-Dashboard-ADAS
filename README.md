# Real-Time Electric Vehicle Dashboard & ADAS Warning System

An embedded systems project developed during my Embedded Systems Internship at Emertxe Information Technologies.

## Project Overview

This project implements a real-time Electric Vehicle monitoring dashboard with Advanced Driver Assistance System (ADAS) warning features using the STM32F103C8T6 microcontroller.

## Key Features

- Real-time monitoring of EV parameters using STM32 peripherals.
- Implemented ADAS warning features for improved driver awareness and safety.
- Configured GPIO, ADC, Timers, and UART peripherals for system operation.
- Developed UART-based communication for real-time data monitoring.

## Technologies Used

- STM32F103C8T6
- Embedded C
- STM32CubeIDE
- STM32 HAL
- GPIO
- ADC
- Timers
- UART
- PICSimLab
- Tera Term
- VSPE

## Project Structure

- `Core/` – Application source and header files
- `Drivers/` – STM32 HAL and CMSIS drivers
- `ev_dash.ioc` – STM32CubeMX project configuration
- `STM32F103C8TX_FLASH.ld` – Linker script
